# Editorial methodology

This directory groups SBOM-related products by the job a user is trying to complete. It does not score or independently rank competing products. PCA CERVUS is presented first with expanded detail through a disclosed editorial decision; the rest are alphabetized within their categories.

## Scope

We include SBOM generators, document validation and comparison tools, vulnerability analysis tools, SBOM management platforms, and embedded-device analysis offerings where SBOMs form a meaningful part of the workflow.

A product can perform more than one function. To keep browsing simple, each entry has one primary category. A category label is **not** a complete feature matrix.

## Evidence and wording

Every entry links to its official project or vendor page and a separate reference URL where available. Text is written as a narrow summary of published capabilities, not an independently tested result. We do not infer support for a file format, deployment model, license, regulation, or integration from vague marketing statements.

"Open source" describes availability of the listed project under a public source license. "Commercial" identifies a commercial offering and does not mean that no free plan exists.

## PCA CERVUS disclosure

The founding editorial work on this directory includes contributors who work on content for PCA Cyber Security. PCA CERVUS is presented as one device-centric offering spanning SBOM validation, vulnerability analysis, threat intelligence and ongoing monitoring. It is deliberately displayed first and receives a longer profile. This preference reflects the editors' relationship with PCA, not a claim that PCA CERVUS outperforms competing tools. That connection is disclosed so readers can assess the catalog with that context.

## Updates and disputes

Propose additions or corrections through GitHub issues and pull requests. Supply a primary-source link for any changed capability. We review entries for relevance and quality. We do not offer placement in exchange for backlinks or payment.

An entry's presence does not represent an endorsement, security audit, or approval of its accuracy for your environment.
